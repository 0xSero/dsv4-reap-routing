2. Observation harness

The harness (observe_religious.py, 22KB) runs read-only TP2 inference on the DGX Spark pair (de5c rank0 + 557f rank1). It:

  • Loads the converted checkpoint (model{0,1}-mp2.safetensors) into vLLM/Sparkinfer
  • Hooks the Gate module's forward() to capture per-token routing (gate weights, activation norms, expert frequencies)
  • Verified line-for-line against model.py Gate.forward — the hook is faithful
  • Asserts fail-closed invariants before accepting any record
  • Writes fsynced JSONL (crash-safe, resume-safe via completed_keys())
  • Supports --raw-budget-tokens for per-token routing capture (needed by Exp 11)

3. Corpus pipeline

  1. Scrape — Project Gutenberg (Gutendex/mirror) + Wikipedia (MediaWiki API). Rate-limited: Gutenberg 0.8–1.5s, Wikipedia 3s with 429 exponential backoff.
  2. Split — Per-book/per-chapter plain text via corpus/split_corpus.py
  3. Tokenize — Pinned tokenizer rev 9e165c30
  4. Window — ≤16,384 tokens per sample; verse numbers stripped from Bible (the digit-confound origin)
  5. Emit — Resumable JSONL + SHA-256 manifests via shared _emit_jsonl

4. REAP metric

REAP = gate_weight × activation_norm. A composite metric for expert importance that combines how strongly an expert is selected (gate weight) with how active it is when selected (activation norm). Computed per-expert per-layer per-sample, then aggregated across samples within a corpus.

5. J-lens probes

Two probes capture the model's intermediate representations:

  • Logit lens — Project the residual stream through the unembedding matrix at each layer to see the model's running next-token guess. Records top-10 tokens + probabilities per position per layer.
  • Bounded Jacobian — Perturb the input embedding by ε=0.01 along 16 random directions, measure output logit change. L2 norm = cheap proxy for the full input-output Jacobian.

Both run on the same 80 samples (10 per tradition, except Upanishads n=3) under the same read-only harness. See J-space lens page for details.

6. Fail-closed guarantees

Every record must pass these invariants before it is accepted:

  • Frequency sum: sum(expert_frequencies) == seqlen × topk for every layer
  • Non-negative: All gate weights and activation norms ≥ 0
  • Finite: No NaN or Inf in any recorded value
  • Shape match: len(expert_frequencies) == 256 for routed layers

Any violation → the record is discarded and the run aborts. Zero violations across all 3,682 records observed to date.

7. Faithfulness verification

The Gate hook was verified line-for-line against the model's Gate.forward() method. The Kimi K3 external review independently reproduced the e164 zero-on-Bible finding from the committed observation artifacts, confirming the harness is faithful.
